# 比較LP 一発生成プロンプト（汎用テンプレート）

**使い方**
1. 「A. 入力シート」の【　】を埋めます。
2. 「B. 共通仕様」はそのまま使います。
3. 素材（サムネ画像・ロゴ・バナー）と一緒に、まとめてAIへ渡します。

入力シートが空欄のところは、AIが公式サイトの公開情報から調べて埋め、出典URLを付けて確認を求めます。

## B. 共通仕様（どの商材でも共通・変更しない）

### B-0. 役割とゴール
- あなたはアフィリエイトLP制作のプロです。
- A-1の商材を比較するLPを、WordPressのカスタムHTMLブロックに貼るだけで完成する1ファイルのコードで作ってください。
- **最優先はスマホでの見やすさ**です。
- 削れる文字はすべて削り、表と見出しで伝えます。冒頭に文字だけが続く構成は離脱率が上がるので禁止です。
- 参考サイトがあれば、それより見やすく、文字が少ないものにします。

### B-1. 技術要件（厳守）
- 1つのコードに `<style>` ＋ `<div id="lp">…</div>` ＋ `<script>` をまとめる
- **空行・HTMLコメント・`&&` を入れない**
  - WordPressが段落タグを自動で挿入して壊れるのを防ぐためです。
  - JavaScriptで「かつ」が必要な場合は、if文の入れ子か自作関数で書きます。
- CSSは `#lp` の中に閉じる
  - 冒頭で `#lp{all:initial}` と主要タグのリセットを行い、テーマのCSSを打ち消します。
  - クラス名はすべて `lp-` で始めます。
- テーマのヘッダー・フッター・ページタイトル・上下余白を非表示にする
  - `body:has(#lp)` を使い、このコードを貼ったページにだけ効かせます。
  - 対象：`header.wp-block-template-part`、`footer.wp-block-template-part`、`.wp-block-post-title`
  - 余白：`main` と、`#lp` を含む `.wp-block-group` の上下 margin・padding を0にします。
  - `.wp-block-post-content:has(#lp){margin-top:0}` も入れます。ページタイトルを入力すると、隠したタイトルの分だけ約19pxの隙間が出るためです。
  - 他のブロックテーマでも効くよう、セレクタは広めに書きます。
- スマホ幅（759px以下）は画面いっぱいに表示する
  - `#lp{width:100vw!important;max-width:100vw!important;margin-left:calc(50% - 50vw)!important;margin-right:calc(50% - 50vw)!important}`
  - 横スクロールは0にします。
  - PCでは中央寄せ・最大幅960px程度にします。
- 画像
  - サムネ（約100KB以下のWebP）は base64 で埋め込みます。
  - ほかの画像はURLで読み込み、`loading="lazy"` と width・height を指定します。
  - Wix画像には `/v1/fit/w_750,h_750,q_75/x.jpg` を付けて圧縮します。
  - ページ全体の転送量は0.6MB以下を目標にします。
- 外部リンク
  - `target="_blank" rel="nofollow sponsored noopener"` と `data-c="商品ID"` を付けます。
- クリック計測
  - リンクを囲む要素に `data-pos` を付けます（compare / quick / 商品ID）。
  - クリック時に `dataLayer.push({event:'aff_click',aff_clinic:商品ID,aff_pos:位置})` を送ります。
  - 商品詳細内は、何番目のボタンかを `-1,-2…` で付けます。
- ページ内リンクはスムーズスクロールにする（prefers-reduced-motion に対応）

### B-2. デザイン方針
- 配色はCSS変数で管理します（メイン・ボタン・黄マーカー `#ffef8a`・金額の赤 `#d2392b`・背景グレー `#f5f6f8`）。
- 余白：白い余白をなくす勢いで広く使います（スマホは左右6px程度）。
- 文字サイズ：本文14〜15.5px、注記11.5〜12px。**最小11px**（表の特徴欄のみ10.5pxまで可）。
- 金額：単位（円など）は小さく、数字は等幅（tnum）にします。
- 表
  - 金額と回数・条件ラベル（ピル型）の高さをそろえ、縦中央に揃えます。
  - ラベルは枠からはみ出さないようにします（長いラベルは「お試し3回」のように短くします）。
- ボタン
  - 主役はボタン色のグラデーションで、右に「＞」を付けます。
  - 1つのブロックに外部ボタンは1つだけにします（同じリンク先のボタンを並べない）。
- 文章
  - 「編集部」表記、AIっぽい定型文（「いかがでしたか」「〜と言えるでしょう」など）、あおり文句は禁止です。
  - 短い言い切りで書きます。

### B-3. ページ構成（上から順）
1. **サムネ（h1）**
   - 画像のみを置き、右上に小さな「PR」ラベルを重ねます。
   - 画像内のボタン位置に透明リンクを重ねます（A-6の位置・飛び先）。
2. **比較表の見出し**
   - 白背景にメインカラーの枠線、下に三角を付けます。
   - 小見出し「料金を一覧で比較」＋本見出し「**人気**【ジャンル】**【N】社/院**」。
   - 強調語はボタン色の文字に黄マーカーを付けます。
3. **比較表**
   - 1列目：ロゴ（公式へリンク）＋名前（詳細へページ内リンク）
   - A-2の列
   - 最後の列：「公式サイト」ボタン
   - 表の下に注意事項を折りたたみで置きます。
4. **選び方3つ**
   - 「3つだけチェック」の見出しの下に、折りたたみを3つ並べます。
5. **まとめカード**（id="lp-quick"）
   - メインカラー背景に、商品ごとの白カードを並べます。
   - 各カード：ロゴ・「こんな人向け」・名前・ミニ表・ポイント2つ
   - ボタン：［詳細を見る（ページ内）］［公式サイトを見る］
6. **商品詳細**（商品ごと）
   - 名前の帯 → 「〇〇な人に」 → バナー（リンク） → 「ここがポイント」3つ
   - → キャンペーン枠（あれば） → 公式ボタン1つ
   - → 料金表：見出し横に「税込・【時点】」。最初の3行だけ表示し、残りは「もっと見る」で開きます。
   - → 注意事項（折りたたみ） → 独自の比較項目（あれば） → ご案内枠（目玉価格＋公式ボタン1つ）
   - バナーの価格表示（税抜など）が表とずれる場合は、バナー直下に注記を入れます。
7. **よくある質問**（5問・折りたたみ）
8. **契約前に知っておくこと**
   - 費用・リスク・解約条件・公的な相談窓口へのリンクを載せます。
9. **フッター**
   - サイト名、運営者情報・プライバシーポリシーへのリンク、PR表記、情報の時点
10. **追従バー**
    - 比較表を過ぎたら下部に表示し、FAQに入ったら隠します。
    - 比較表へ戻るボタンにします。
    - PCでは非表示です。

- **独自項目の表示**：画像がASPの素材や許可済みのものでない場合は、写真を使わず文字で表示します。
  - 種類ごとの内訳（例：「熱破壊式 3台／蓄熱式 1台」）と、1行ずつのリスト（自作のSVGアイコン＋種類ラベルを色分け）で見せます。

### B-4. 全ジャンル共通のルール
- **ステマ規制**
  - サムネに「PR」ラベルを付けます。
  - フッターに「【PR】本記事は広告（アフィリエイトリンク）を含みます。掲載順は優劣を示すものではありません。」を入れます。
- **景品表示法**
  - 「最安」「No.1」「業界初」などは根拠と出典がない限り使いません。
  - 料金は税込で書き、条件（初回限定・一括払い・期間限定など）は必ず近くに書きます。
  - 「情報の時点」を明記します。
- **素材**
  - ロゴ・バナー・商品画像は、ASPの素材か公式の許可を得たものだけを使います。
  - 他社の比較サイトの画像や文章は流用しません。構成を参考にするのは問題ありません。
- **データ**
  - 公式サイトの公開情報だけを使い、推測で数字を作りません。
  - 調べた値は出典URLを添えて報告し、確認できない値は空欄にして質問します。

### B-5. 規制カテゴリ別ルール（A-7で選んだものを適用）
- **医療（医療広告ガイドライン）**
  - 禁止：ランキング・順位・星評価・比較優良表現、口コミ・体験談、ビフォーアフター写真（条件を満たさない限り）、効果の断定（「ずっと」「必ず」「不要に」など）。
  - 必須：自由診療である旨、費用、主なリスク・副作用、個人差がある旨。
  - 相談窓口：医療安全支援センター、消費者ホットライン。
  - 未承認医療機器を載せる場合は、未承認であること・入手経路・国内承認品の有無・海外の安全性情報を明記します（公式の注記をそのまま使います）。
- **薬機法・健康増進法**
  - 禁止：病気の治療・予防効果、身体の構造や機能への作用の表現（「痩せる」「シミが消える」「髪が生える」など）、医薬品と誤認させる表現、体験談による効果の示唆。
  - 化粧品は承認された効能の範囲内だけで書きます。
  - 機能性表示食品・トクホは、届出・許可の表示どおりにだけ書きます。
- **金融**
  - 実質年率・返済方式・遅延損害金・審査があることなどを明記します。
  - 「必ず借りられる」「誰でも審査に通る」は禁止です。
  - 投資は元本割れリスクを明記し、運用成績の断定は禁止です。
  - 証券・FXなどは登録番号の表示を確認します。
- **通信・サブスク**
  - 実質料金の計算根拠、キャンペーン適用条件、最低利用期間・解約金、速度は「ベストエフォート」であることを明記します。
- **人材・教育**
  - 「必ず転職できる」「年収〇〇万円アップ保証」など、成果の断定は禁止です。
  - 合格率・実績は母数と時点を明記します。
- **一般**
  - B-4のみを適用します。

### B-6. 付属ページ（別コードで納品）
- 運営者情報とプライバシーポリシーの2ページを作ります。
- コードの作り方はLPと同じです：WordPress対応、`#lpp` に閉じたCSS、テーマのヘッダー・フッター・タイトル・余白を非表示にします。
- 各ページの最後に、LPへ戻るリンクともう片方のページへのリンクを置きます。
- **運営者情報**
  - サイト名、URL、運営者、所在地、問い合わせ先
  - 運営目的
  - 広告（アフィリエイト）についての説明
  - 掲載情報・免責についての説明
- **プライバシーポリシー**
  - 個人情報の利用目的、第三者への提供
  - Googleアナリティクス（Cookie）、広告（ASPのCookie）
  - 免責事項、著作権、ポリシーの変更
  - 問い合わせ先、制定日

### B-7. 納品前の自己チェック（実行して結果を報告）
- 375px・390px・1280pxの各幅で、横スクロール0・画像の表示切れなし・JSエラーなしを確認します。
- WordPressのブロックテーマ（twentytwentyfive）の枠に入れた状態で、次を確認します。
  - ヘッダー・フッターが消えている
  - サムネが画面の最上部（上の余白0px）から始まる
- サムネのボタンが指定の飛び先へ移動する
- 表のラベルがはみ出していない、金額の高さがそろっている
- コードに空行・HTMLコメント・`&&` が含まれていない
- B-5の禁止表現を全文で検索し、0件であることを報告する
