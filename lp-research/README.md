## #0 自社：ゴリラクリニック脱毛 PR記事（WordPress用 v2）

- 形式：1社特化のPR記事（LINE風会話 → 先に結論 → コース表 → 特徴 → 他の方法との比較 → 向き不向き → 流れ → 費用・リスク → FAQ → まとめ）
- 料金：ヒゲ脱毛スタートプラン **16,800円／3回**（※競合#1の記載では9,800円 → 要確認）
- 強み：リスク・副作用の説明、誠実な書き方、不安の解消（価格・痛み・勧誘）、カウンセリングで聞くことのチェックリスト、FAQ
- 課題：
  - PR表記が末尾だけ（`.gc-pr-note` が未使用）
  - `wp:html` が二重
  - アバター画像が http
  - `blue-title` が div（h2 にすべき）
  - 料金の数字が少ない、急ぐ理由がない、画像がない、ボタンの色が弱い、追従ボタンなし
  - ボタンのリンクがすべて同じ `AFFILIATE_URL`（場所別に計測できない）

- 形式：複数社のランキングLP（医療／エステをタブで切替、比較表、各社の詳細、脱毛機スライダー、院一覧、離脱時の診断ポップアップ）

- エステランキング：1 RINX(4.7) / 2 メンズストラッシュ(4.5) / 3 RBL(4.2)
- ゴリラクリニックの記載：
  - ヒゲ3部位（鼻下・アゴ・アゴ下）3回 **9,800円**（税込、初回契約者向けスタートプラン）／月々3,300円
  - 全身5回 296,800円／月々5,800円
  - **回数コース全品10％OFF、2026/10/31契約分まで**（スタートプランとの併用不可、一部対象外あり）
  - 脱毛機5種類：ジェントルヤグプロ、メディオスターNeXT PRO、ジェントルレーズPRO、ライトシェアデュエット（スライダーの掲載は4機種）
  - 笑気麻酔と麻酔クリーム、対象プランなら麻酔クリーム1回分が初回0円

  - レジーナ：ヒゲ3回9,900円、麻酔無料（デビュープランを除く）、追加費用0円
  - メンズリゼ：ヒゲ5回14,000円、YAGレーザー、返金保証

- 参考になる点：
  - 料金と月額の数字
  - ◎○の評価アイコン
  - 地域別の院一覧

  - 計測タグが豊富（FB / Yahoo / LINE / TikTok / Bing / Google広告 / Clarity）

  - リスク・副作用の説明がない

  - 検索エンジン向けの隠し見出し（`seo-hidden-heading`）
  - PR表記が小さい
  - クリニック同士の順位付け（比較優良広告のおそれ）
  - HTMLの不備や計測タグの重複
  - ウィルビーの料金が比較表と詳細で違う

## #2 競合：メンズ脱毛比較ナビ「医療脱毛ぶっちゃけどこがいい？総合人気３選」

- URL：https://v2-mens.datumo-hikaku.jp/ranking/total-clinic-search1/（運営：株式会社Interg）
- 流入：Google検索広告（キーワード「メンズ脱毛」、gclid / utm 付き）。`noindex` の広告専用LP
- 作り：Nuxt＋microCMS。CMS上の管理名から、キーワードのマッチタイプ別にLPを出し分けている（「_totalインテントマッチ用」「_total完全一致用」）。`compareEffectiveAb` などの項目名からABテストもしているとみられる
- 形式：3社に絞ったランキング（多すぎない）
  - 1位 エミナル：ヒゲ3回8,400円、全身5回159,500円（蓄熱式）、麻酔無料
  - 2位 レジーナ：ヒゲ3回9,900円、全身5回258,000円、麻酔無料
  - 3位 メンズリゼ：ヒゲ5回14,000円、全身5回229,800円、麻酔有料
- **ゴリラクリニックのデータ**（コラム記事内で4位として掲載、ASP は adlocate）
  - ヒゲ3回 **9,800円は初めて契約する人限定**。**契約歴がある人は通常料金16,800円** → 自社LPの16,800円との食い違いはこれが原因とみられる
  - 条件：照射は平日11〜20時のみ、機械は選べない、2回目以降は笑気麻酔・麻酔クリームが使えない、他の割引やヒゲプランとの併用不可
  - 【10月31日まで】初めて契約する人は麻酔無料（初回の麻酔クリーム1回無料）
  - 全身5回296,800円（月6,000円）、顔全体6回76,800円（月3,400円）、VIO5回99,800円、腕・脚5回各158,800円
  - 実績500万件以上、男性スタッフ多数、営業11〜20時、キャンセルは前日20時まで無料
- 参考になる点：
  - 冒頭に「※このサイトはプロモーションを含みます」（最下部にも表示）
  - 「昨日○人が予約に進みました」の人数表示（点滅アニメーション付き）
  - 比較表を「料金／サービス／実績」のタブで切り替え、◎○△アイコンで評価
  - 部位別に「総額・1回あたり・月額」の表を掲載
  - **ボタンを2つ並べる**：「無料カウンセリングに進む」（予約フォームへ直接）＋「公式サイトを見る」
  - 部位ごとにアフィリエイトリンクを分け、GTM でボタンの場所（`data-gtm-cta-position`）を計測
  - 近くの店舗検索（地方 → 都道府県 → 店舗の3段階）、脱毛機のスライダー（痛みの強さ付き）
  - 「ご利用前の注意事項」を折りたたみで掲載（医療ローンの回数・総額などの条件まで書いている）
  - 下部のコラムで、医療脱毛とサロン脱毛の違い、副作用（やけど・毛嚢炎・硬毛化）、保険適用外、追加費用、相談窓口（医療安全支援センター・消費者ホットライン）を説明
  - 調査概要・編集方針・運営会社を明記
  - 悩み別の記事LP（青ヒゲ／カミソリ負け／後悔しない選び方／ジェントルマックスプロ／ヤグレーザー）から、ランキングや1社推しへ誘導
    - 流れ：悩みの提示 →「後悔した理由」と対策 → 体験の声 →「失敗しないための3箇条」→ 3社紹介 → 最後に1社推し
- 弱点：
  - 誇張表現（「永久脱毛」「コスパ最強」「圧倒的な人気」「最もオススメ」「青ヒゲから解放されます」）
  - 「当ページ利用者の70％が選択」など根拠のない数字
  - レジーナの説明に、エミナルの数字（症例数440万件）がそのまま流用されている
  - 相場がページ内で矛盾（FAQ「ヒゲ5回6〜10万円」／コラム「3〜4万円」）
  - 誤字（「バリア昨日」「びげ定期」など）
  - 体験の声が一般論で、実際の口コミではない
